# AI Agent Exploration Profile

## 技术栈
- **AI Agent 平台**：Grok（xAI）、NotebookLM、Claude、ChatGPT 等主流 Agent 系统
- **工具集成**：Notion Connector、Gmail、GitHub Connector、多 SaaS 工具链打通
- **核心能力**：Agent 能力测试、工具调用（Tool Use）、多轮任务执行、上下文管理
- **关注技术**：Agent 自主性、工具集成稳定性、Memory 机制、RAG 增强、工作流自动化

## 实践经验
- 深入测试 AI Agent 在真实生产力场景中的可用性
- 擅长多工具链路集成与端到端验证（Notion + Gmail + GitHub 等）
- 重点探索 Agent 的**工具调用准确性**、**长期上下文保持**、**错误恢复能力**
- 持续进行 Agent 边界测试，包括 CRUD 操作、文件管理、邮件处理、代码仓库交互等
- 对 Agent 的**可靠性**和**幻觉控制**有较强敏感度

## 工作风格
- 测试驱动，注重实际结果而非理论
- 沟通直接，善于发现并清晰反馈 Agent 的问题点
- 追求稳定、可落地的工作流方案
- 对 AI Agent 的长期发展保持持续关注和实践
